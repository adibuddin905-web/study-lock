# Study Lock

Windows study app: 50 min full-screen lock + 10 min break (all customizable),
stopwatch, daily hours, streak, doubts list and a built-in study audio player.

## Download (no Python needed)
Go to **Releases** and download `StudyLock.exe`, then double-click it.
(Windows SmartScreen may warn because the app is unsigned: More info -> Run anyway.)

## Emergency exit
Ctrl+Alt+Del or Ctrl+Shift+Esc -> Task Manager -> end `StudyLock.exe`.

## Run from source
`python study_lock.py` (Python 3.9+, no extra packages)
